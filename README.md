The funniest one-line excuse an AI agent gives for a missed deadline, written by `main.py` to `/output/entry.txt` for the [Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e) competition on make.fun.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python stdlib, deterministic, no network, no input files.
